# Приглашение на юбилей Людмилы

Электронное приглашение для коллег: конверт, письмо, дата, локация и анкета гостя. Открой `index.html` на телефоне — так смотрят гости.

После публикации на GitHub Pages ссылка будет такой:

https://aytalykt-lab.github.io/Lyudmila-s-anniversary/

## Как открыть сейчас

1. Двойной клик по `index.html` или из этой папки:
   `python3 -m http.server 8766` → http://127.0.0.1:8766/
2. Все факты вечера правятся в `config.js`: имя, возраст, дата, зал, карта, WhatsApp / Max, ссылка на таблицу гостей.

## Что уже внутри

- Конверт с печатью «Л» → открытие письма
- Юбилейная палитра: бордо, золото, кремовый
- Дата: суббота, 26 сентября 2026, 18:00, Якутск
- Таймер до праздника
- Локация — ресторан «Новый Пекин», ул. Герцена, 3
- Анкета гостя: имя и фамилия, «Приду» / «Не приду»
- Группа MAX для фото вечера
- Музыка после открытия конверта

## Что ещё можно подставить

- Ссылку на группу MAX в `maxGroupLink`
- Номер WhatsApp или ссылку на чат Max
- URL таблицы гостей в `sheetsUrl`
